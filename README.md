## 🏛️ O Conceito (The Brand Soul)

A **Kalia Educacional** nasce da missão de restaurar a ordem e a beleza na educação infantil. O propósito central é oferecer às crianças uma visão de mundo direcionada ao **Bem**, ao **Belo (Kalos)** e à **Verdade**.

### Arquétipos Dominantes
- **O Governante (The Ruler):** Exala ordem, estabilidade e clareza. A educação como uma fortaleza segura e bem estruturada.
- **O Criador (The Creator):** A liberdade através da ordem. Materiais concebidos em blocos que permitem a educadores e pais a construção criativa sobre uma base sólida.

## 🎨 Identidade Visual

### Simbologia
- **O Castelo Geométrico:** Representa solidez, proteção e a construção clássica das virtudes.
- **Blocos de Construção:** Metáfora da alvenaria lógica; cada bloco é um módulo de ensino coeso e sequencial.
- **A Bandeira ao Topo:** Símbolo da vitória e conquista intelectual ao final do processo educativo.

### Paleta de Cores
A paleta foi selecionada para transmitir prestígio acadêmico e autoridade intelectual:

| Cor | Hex | Significado |
| :--- | :--- | :--- |
| **Primary** | `#1B365D` | Ordem, Profundidade e Instituição |
| **Secondary** | `#D1A27A` | Tradição, Calidez e Elegância |
| **Accent** | `#C85A43` | Energia Criativa e Atenção |
| **Background**| `#F9F6F0` | Pureza, Clareza e Leveza |

### Tipografia
- **Primária (Títulos):** `Lora` — Uma fonte serifada que evoca tradição e academicismo.
- **Secundária (Corpo):** `Outfit` — Moderna, geométrica e altamente legível.

## 🛠️ Stack Técnica

Este projeto é uma **Next.js Landing Page** construída com as tecnologias mais modernas do ecossistema React, focando em performance e estética premium.

- **Framework:** [Next.js 16](https://nextjs.org/) (App Router)
- **Linguagem:** [TypeScript](https://www.typescriptlang.org/)
- **Estilização:** [Tailwind CSS](https://tailwindcss.com/)
- **Animações:** [Framer Motion](https://www.framer.com/motion/)
- **Componentes UI:** [Radix UI](https://www.radix-ui.com/) & [Lucide React](https://lucide.dev/)
- **Carrosséis:** [Embla Carousel](https://www.embla-carousel.com/)
- **Validação:** [Zod](https://zod.dev/)

### Diferenciais de Implementação
- **Componentização Atômica:** Seguindo os padrões de Design System da Nexus.
- **Animações Fluídas:** Uso de `framer-motion` para transições elegantes e micro-interações.
- **SEO Ready:** Implementação de metadados dinâmicos e `react-helmet`.
- **Performance:** Otimização de imagens e fontes nativa do Next.js.

## 🚀 Como Executar

1. **Instale as dependências:**
   ```bash
   npm install
   ```

2. **Rode o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```

3. **Build para produção:**
   ```bash
   npm run build
   ```
